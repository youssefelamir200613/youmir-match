# YOUMIR MATCH — مشروع Android

هذا مشروع مصدر أولي لتطبيق مباريات عربي بتصميم داكن. يحتوي على شاشة مباريات تجريبية ومشغل HLS لروابط HTTPS التي تملك حق بثها.

## استخراج APK من الموبايل فقط عبر GitHub Actions

1. افتحي https://github.com وسجّلي الدخول أو أنشئي حساباً.
2. اضغطي + ثم New repository.
3. اكتبي الاسم `youmir-match` واختاري Public (حتى تتاح GitHub Actions بسهولة للمستودع العام)، ثم Create repository.
4. من صفحة المستودع اختاري Add file ثم Upload files.
5. فكّي ضغط ملف ZIP هذا أولاً على هاتفك، ثم ارفعي محتويات المجلد كلها إلى المستودع مع الحفاظ على المجلدات.
6. افتحي تبويب Actions ووافقي على تفعيل GitHub Actions إذا ظهر الطلب.
7. افتحي workflow باسم `Build Android APK` ثم اضغطي Run workflow.
8. انتظري حتى ينتهي التنفيذ بعلامة نجاح خضراء.
9. افتحي عملية البناء الناجحة، وانزلي إلى Artifacts، ثم حمّلي `YOUMIR-MATCH-debug-apk`.
10. فكّي ضغط ملف Artifact على الهاتف. ستجدين `app-debug.apk` ويمكنك تثبيته.

## إضافة روابط بثك المرخصة
افتحي `app/src/main/java/com/youmir/match/MatchData.kt` وعدّلي `streamUrl` لكل مباراة إلى رابط HTTPS مباشر بصيغة HLS مثل `.m3u8`، بشرط امتلاك حقوق استخدامه. ارفعي التعديل إلى GitHub وشغّلي البناء مجدداً.

## تنبيه
- هذا مشروع تجريبي أولي؛ أسماء الفرق والنتائج أمثلة وليست بيانات مباشرة.
- لا يحتوي على اشتراكات أو قاعدة بيانات أو خدمة نتائج لحظية.
- ملف APK الناتج Debug للتجربة، وليس إصداراً منشوراً على متجر Google Play.
